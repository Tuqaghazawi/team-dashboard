# Guidelines

Place licensed NCCN PDFs here; record version, e.g. 2.2026. Never commit.

`data/guidelines/*.pdf` is gitignored. These documents are licensed — committing
them would redistribute them. Keep a note of which version each file is, because
a retrieval answer is only meaningful against a known guideline version.
